ICE Page

ICE stands for In Class Excercises. This is a collection of all the projects I've worked on in class. The following are some projects:

  • Apostles

    This project was for the main purpose of practicing grid while I was being introduced to the topic and using it to position images. This one helped me learned the basics of grid and how to use it.

  • President Oaks

    This project was to practice grid some more as well as styling in CSS. Also to familiarize myself with importing font families and using them in CSS. This one helped me learn how CSS is vital to making things look good.

  • Favorite Devotional

    This project was to understand how to use user interactivity elements in HTML. I learned how to use those elements and also that they do not work without JavaScript.

  • Flags

    This project had us using grid and CSS styling to make flags of other countries. I learned how to better use grid.

  • Positioning

    This project had puzzles I needed to figure out through grid positioning in CSS without touching the HTML. I needed to make the grid look like the example images. I learned how to use grid to position things in a very precise manner.

  • Gallery

    This project had large image file sizes that needed to be downscaled for easier use. With this one, we switched the png images to jpg's and then made thumbnail versions of the images by shrinking the images. I learned that images should be small in size for users with bad internet.

  • Signup

    This one acted as a final project for our ICE challenges by combining everything we knew. I used grid to position elements, used the user interactivity elements I learned, and used CSS to style everything. This one helped me to learn how to put all of what I learned previously together.
